# Fitoor 2026

Website for Fitoor, Plaksha University's annual cultural fest (Nov 14–15, 2026).

Built with Next.js (App Router), TypeScript, Tailwind CSS, and Motion.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. Pages live under `app/`, editable content lives under `data/`.

## Deployment

Deployed to Vercel from the `main` branch.
